# **App Name**: Academia Archive

## Core Features:

- Secure Login: Secure login using college ID (@mitsgwl.ac.in).
- Paper Filtering: Select department, subject, and year to filter papers.
- Paper Listing: List available papers based on user input.
- Paper Download: Download papers directly from the website.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a sense of knowledge and trust.
- Background color: Light gray (#F0F2F5), a desaturated version of indigo, creating a clean backdrop.
- Accent color: Soft orange (#FFAB40) to highlight key actions and navigation.
- Body and headline font: 'Inter' (sans-serif) for a modern, objective look, readable on screen.
- Use simple, clear icons for departments and file types.
- Clean, card-based layout for displaying papers with clear categorization.
- Subtle transition animations on filtering and downloading for feedback.
